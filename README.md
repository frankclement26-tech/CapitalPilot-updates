# CapitalPilot — mises à jour

Ce dépôt public contient uniquement les paquets d’installation Linux de CapitalPilot, le manifeste `latest.json` et les notes de version.

Il ne contient ni le code source ni les données financières de l’application.

CapitalPilot vérifie le manifeste officiel puis valide l’intégrité de chaque paquet avec SHA-256 avant installation.
